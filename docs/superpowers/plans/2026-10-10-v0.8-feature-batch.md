# KMctrl 0.8 Feature Batch Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship KMctrl 0.8.0: fix the Magic Mouse swipe capture drop, add a unit-test target, layout-independent typing, media keys, mouse sensitivity, a re-grab hotkey, remote display wake, a GitHub update check, and clipboard sync.

**Architecture:** All work stays inside the existing split — `ControlHost` (controlling Mac: capture + send), `ControlManager`/`ControlInjector` (controlled Mac: receive + inject), `AppSettings` (UserDefaults-backed), SwiftUI views. New pure value types (`KeyCharacters`, `MediaKey`, `AppVersion`, `ClipboardPayload` limits) carry the logic so XCTest can cover it; AppKit/CoreGraphics/IOKit glue stays thin and untested. Wire protocol is versioned (`SessionHello.version` 2, `ControlAck.version`) so new event kinds are only sent to peers that understand them.

**Tech Stack:** Swift 5, SwiftUI + AppKit, CoreGraphics (`CGEvent`), Carbon (`RegisterEventHotKey`), IOKit.pwr_mgt, Network.framework / POSIX sockets (existing), XCTest. Xcode 27, macOS 13+ deployment target.

**Spec:** `docs/superpowers/specs/2026-10-10-v0.8-feature-batch-design.md`

## Global Constraints

- Deployment target stays macOS 13.0; no API newer than 13 without `#available`.
- App Sandbox stays on (`KMctrl.entitlements` unchanged); no new TCC permission is required on the controlling Mac for any feature.
- `ControlEventKind.wireOrder` is append-only: `.mediaKey` = byte 10, `.wakeDisplay` = byte 11.
- JSON control frames with none of the new fields must stay byte-identical to 0.7.1.
- Edge mode code paths are not modified.
- Build: `xcodebuild -scheme KMctrl -configuration Debug build` and `xcodebuild -scheme KMctrl test` pass after every task.
- Version at the end: `CFBundleShortVersionString` 0.8.0, `CFBundleVersion` 14.
- Commits: one per task, message prefixed `KMctrl:` like the existing history, ending with `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`.

## Review Focus

1. A 0.7.1 controlled Mac paired with a 0.8 controller on the JSON path must keep working: no `chars`, `.mediaKey`, or `.wakeDisplay` is ever sent to it. (Task 3 tests `ControlAck` default version; Task 4/5/8 gate on `peerVersion >= 2`.)
2. Binary legacy frame (exactly 44 bytes) must still decode after the trailer is added. (Task 4 test `testLegacy44ByteFrameDecodes`.)
3. A `chars` value longer than 32 UTF-8 bytes (IME commit of a long string) must not corrupt the binary frame. (Task 4 test `testOversizeCharsDroppedInBinary`.)
4. A clipboard change on one Mac must not bounce back and forth forever once mirrored. (Task 10 test `testEchoSuppressionIgnoresOwnWrite` on the pure `ClipboardSyncState`.)
5. An update-check response with a malformed or pre-release tag (`v0.8.0-beta`, `nightly`) must not show a bogus "update available". (Task 9 test `testUnparseableTagIsNotNewer`.)

```swift
/// Window mode needs focus. A Magic Mouse / trackpad system swipe can switch Space and
/// briefly deactivate us; only end capture if we are still inactive after a short grace.
private func handleResignActive() {
    guard state == .capturing, !edgeModeEnabled else { return }
    let front = NSWorkspace.shared.frontmostApplication?.localizedName ?? "?"
    DebugLog.log("control host: resigned active during capture (front: \(front)) — grace check in 250 ms", .warn)
    DispatchQueue.main.asyncAfter(deadline: .now() + 0.25) { [weak self] in
        guard let self, self.state == .capturing else { return }
        if NSApp.isActive {
            DebugLog.log("control host: re-activated within grace — capture kept")
        } else {
            DebugLog.log("control host: still inactive after grace — releasing", .warn)
            self.endCapture()
        }
    }
}
```

```swift
struct ControlAck: Codable {
    var accepted: Bool
    var reason: String = ""
    /// Control protocol version the controlled Mac speaks. Absent from 0.7.x peers → 1.
    var version: Int = 1

    init(accepted: Bool, reason: String = "", version: Int = 1) {
        self.accepted = accepted; self.reason = reason; self.version = version
    }
    init(from decoder: Decoder) throws {
        let c = try decoder.container(keyedBy: CodingKeys.self)
        accepted = try c.decode(Bool.self, forKey: .accepted)
        reason = try c.decodeIfPresent(String.self, forKey: .reason) ?? ""
        version = try c.decodeIfPresent(Int.self, forKey: .version) ?? 1
    }
}
```

`KeyCharacters.swift`:

```swift
import Foundation
import CoreGraphics

/// Decides whether a key-down's typed characters should travel with the event so the
/// controlled Mac types what the controller's layout produced, not what its own layout maps
/// that key code to.
enum KeyCharacters {
    /// Max UTF-8 bytes carried in the binary trailer; longer strings are dropped (keycode only).
    static let maxBytes = 32

    static func override(for chars: String?, flags: UInt64) -> String? {
        guard let chars, !chars.isEmpty else { return nil }                 // dead key / none
        let f = CGEventFlags(rawValue: flags)
        if f.contains(.maskCommand) || f.contains(.maskControl) { return nil } // shortcuts: keycode
        for scalar in chars.unicodeScalars {
            let v = scalar.value
            if v < 0x20 || v == 0x7F { return nil }                          // control chars
            if (0xF700...0xF8FF).contains(v) { return nil }                  // NSEvent function-key PUA
        }
        return chars
    }
}
```

```swift
    var dx: Double = 0
```

```swift
/// Media/aux key as carried in an `NSEvent` of type `.systemDefined`, subtype 8
/// (NX_SUBTYPE_AUX_CONTROL_BUTTONS). `data1` packs key type, state and repeat flag.
struct MediaKey: Equatable {
    let key: Int        // NX_KEYTYPE_* (0 soundUp, 1 soundDown, 2 brightUp, 3 brightDown, 7 mute,
                        // 16 play, 17 next, 18 previous, 19 fast, 20 rewind, 21/22 illumination)
    let isDown: Bool
    let isRepeat: Bool

    static let subtypeAuxControl = 8
    static let forwarded: Set<Int> = [0, 1, 2, 3, 7, 16, 17, 18, 19, 20, 21, 22]

    static func decode(data1: Int) -> MediaKey? {
        let state = (data1 >> 8) & 0xFF
        guard state == 0x0A || state == 0x0B else { return nil }
        return MediaKey(key: (data1 >> 16) & 0xFFFF, isDown: state == 0x0A, isRepeat: data1 & 1 == 1)
    }

    var data1: Int { (key << 16) | ((isDown ? 0x0A : 0x0B) << 8) | (isRepeat ? 1 : 0) }
}
```

```swift
import AppKit

/// Global hotkey via Carbon `RegisterEventHotKey` — needs no Accessibility/Input Monitoring,
/// so it works inside the sandbox and on an MDM-managed Mac. Fixed combo: ⌃⌥⌘K.
@MainActor
final class HotkeyMonitor {
    static let keyCodeK: UInt32 = 40
    static let modifiers: UInt32 = UInt32(controlKey | optionKey | cmdKey)
    static let label = "⌃⌥⌘K"

    private var ref: EventHotKeyRef?
    private var handler: EventHandlerRef?
    private let onPress: () -> Void

    init(onPress: @escaping () -> Void) { self.onPress = onPress }

    func setEnabled(_ on: Bool) {
        if on { register() } else { unregister() }
    }

    private func register() {
        guard ref == nil else { return }
        var spec = EventTypeSpec(eventClass: OSType(kEventClassKeyboard), eventKind: UInt32(kEventHotKeyPressed))
        let selfPtr = Unmanaged.passUnretained(self).toOpaque()
        InstallEventHandler(GetApplicationEventTarget(), { _, _, userData in
            guard let userData else { return noErr }
            let me = Unmanaged<HotkeyMonitor>.fromOpaque(userData).takeUnretainedValue()
            Task { @MainActor in me.onPress() }
            return noErr
        }, 1, &spec, selfPtr, &handler)
        let id = EventHotKeyID(signature: OSType(0x4B4D4354) /* 'KMCT' */, id: 1)
        RegisterEventHotKey(HotkeyMonitor.keyCodeK, HotkeyMonitor.modifiers, id,
                            GetApplicationEventTarget(), 0, &ref)
        DebugLog.log("hotkey: \(HotkeyMonitor.label) registered (re-grab)")
    }

    private func unregister() {
        if let ref { UnregisterEventHotKey(ref) }; ref = nil
        if let handler { RemoveEventHandler(handler) }; handler = nil
    }
}
```

```swift
import Foundation

/// Dotted numeric version ("0.8.0", "v1.2"). Anything else (pre-release suffixes, words) is
/// unparseable → nil, so it can never be reported as "newer".
struct AppVersion: Comparable, Equatable {
    let parts: [Int]

    init?(_ raw: String) {
        var s = raw.trimmingCharacters(in: .whitespaces)
        if s.hasPrefix("v") || s.hasPrefix("V") { s.removeFirst() }
        guard !s.isEmpty else { return nil }
        let p = s.split(separator: ".", omittingEmptySubsequences: false).map { Int($0) }
        guard !p.isEmpty, p.allSatisfy({ $0 != nil }) else { return nil }
        parts = p.map { $0! }
    }

    static var current: AppVersion? {
        AppVersion(Bundle.main.infoDictionary?["CFBundleShortVersionString"] as? String ?? "")
    }

    private func padded(to n: Int) -> [Int] { parts + Array(repeating: 0, count: max(0, n - parts.count)) }
    static func == (a: AppVersion, b: AppVersion) -> Bool {
        let n = max(a.parts.count, b.parts.count); return a.padded(to: n) == b.padded(to: n)
    }
    static func < (a: AppVersion, b: AppVersion) -> Bool {
        let n = max(a.parts.count, b.parts.count)
        return a.padded(to: n).lexicographicallyPrecedes(b.padded(to: n))
    }
}

struct ReleaseInfo: Codable {
    struct Asset: Codable { let name: String; let browser_download_url: String }
    let tag_name: String
    let html_url: String
    let assets: [Asset]
    /// First asset that looks like the app zip (KMctrl-*.zip, not a dSYM).
    var downloadURL: URL? {
        let pick = assets.first { $0.name.hasPrefix("KMctrl-") && $0.name.hasSuffix(".zip") && !$0.name.contains("dSYM") }
        return (pick?.browser_download_url ?? html_url).flatMap(URL.init(string:))
    }
}
```

```swift
import Foundation

@MainActor
final class UpdateChecker: ObservableObject {
    struct Available: Equatable { let version: String; let url: URL }
    @Published private(set) var available: Available?
    @Published private(set) var lastChecked: Date?
    @Published private(set) var checking = false
    @Published private(set) var lastError: String?

    static let endpoint = URL(string: "https://api.github.com/repos/jbull79/kmctrl/releases/latest")!
    static let interval: TimeInterval = 24 * 3600
    private let defaults = UserDefaults.standard
    private enum Keys { static let last = "kmctrl.update.lastChecked"; static let tag = "kmctrl.update.latestTag"; static let url = "kmctrl.update.latestURL" }
    private var timer: Timer?
    var isEnabled: () -> Bool = { true }

    init() {
        lastChecked = defaults.object(forKey: Keys.last) as? Date
        if let tag = defaults.string(forKey: Keys.tag), let u = defaults.string(forKey: Keys.url).flatMap(URL.init(string:)) {
            available = Self.evaluate(tag: tag, url: u)
        }
    }

    /// Call at launch: first check after 5 s if due, then every 24 h while running.
    func start() {
        DispatchQueue.main.asyncAfter(deadline: .now() + 5) { [weak self] in self?.checkIfDue() }
        timer = Timer.scheduledTimer(withTimeInterval: 3600, repeats: true) { [weak self] _ in
            Task { @MainActor in self?.checkIfDue() }
        }
    }

    func checkIfDue() {
        guard isEnabled() else { return }
        if let t = lastChecked, Date().timeIntervalSince(t) < Self.interval { return }
        Task { await checkNow() }
    }

    func checkNow() async {
        guard !checking else { return }
        checking = true; lastError = nil
        defer { checking = false }
        do {
            var req = URLRequest(url: Self.endpoint)
            req.setValue("application/vnd.github+json", forHTTPHeaderField: "Accept")
            let (data, resp) = try await URLSession.shared.data(for: req)
            guard (resp as? HTTPURLResponse)?.statusCode == 200 else { throw URLError(.badServerResponse) }
            let info = try JSONDecoder().decode(ReleaseInfo.self, from: data)
            let url = info.downloadURL ?? URL(string: info.html_url)!
            available = Self.evaluate(tag: info.tag_name, url: url)
            lastChecked = Date()
            defaults.set(lastChecked, forKey: Keys.last)
            defaults.set(info.tag_name, forKey: Keys.tag)
            defaults.set(url.absoluteString, forKey: Keys.url)
            DebugLog.log("update: latest \(info.tag_name) — \(available == nil ? "up to date" : "update available")")
        } catch {
            lastError = error.localizedDescription
            DebugLog.log("update: check failed — \(error.localizedDescription)", .warn)
        }
    }

    /// nil unless `tag` parses and is strictly newer than the running app.
    static func evaluate(tag: String, url: URL) -> Available? {
        guard let latest = AppVersion(tag), let cur = AppVersion.current, cur < latest else { return nil }
        return Available(version: latest.parts.map(String.init).joined(separator: "."), url: url)
    }
}
```

```swift
/// Tracks NSPasteboard.changeCount so we send real user copies and ignore our own writes.
struct ClipboardSyncState {
    private var lastSeen: Int?
    private var ownWrite: Int?

    /// Returns true when `count` is a new, user-originated change worth sending.
    mutating func noteLocalChange(count: Int) -> Bool {
        defer { lastSeen = count }
        guard let last = lastSeen, count != last else { return false }
        if count == ownWrite { ownWrite = nil; return false }
        return true
    }
    mutating func noteOwnWrite(count: Int) { ownWrite = count; lastSeen = count }
}
```

```swift
import AppKit

/// Mirrors text/PNG clipboard changes to the session peer over short-lived `.clipboard`
/// sessions (never on the control stream). Active only while a control session exists.
@MainActor
final class ClipboardSync {
    private let settings: AppSettings
    private let localName: () -> String
    private var state = ClipboardSyncState()
    private var timer: Timer?
    private var peerResolver: (() -> Peer?)?
    private var sending = false
    private var pendingResend = false

    init(settings: AppSettings, localName: @escaping () -> String) { self.settings = settings; self.localName = localName }

    func setActive(_ on: Bool, peerResolver: @escaping () -> Peer?) {
        self.peerResolver = on ? peerResolver : nil
        timer?.invalidate(); timer = nil
        guard on else { return }
        state = ClipboardSyncState()
        _ = state.noteLocalChange(count: NSPasteboard.general.changeCount)   // baseline
        timer = Timer.scheduledTimer(withTimeInterval: 0.5, repeats: true) { [weak self] _ in
            Task { @MainActor in self?.poll() }
        }
        DebugLog.log("clipboard: sync active")
    }

    private func poll() {
        guard settings.clipboardSyncEnabled, state.noteLocalChange(count: NSPasteboard.general.changeCount) else { return }
        guard let payload = Self.readLocal(), !payload.isEmpty else { return }
        guard payload.isWithinLimits else { DebugLog.log("clipboard: change too large, skipped", .warn); return }
        send(payload)
    }

    private func send(_ payload: ClipboardPayload) {
        guard !sending else { pendingResend = true; return }
        guard let peer = peerResolver?() else { DebugLog.log("clipboard: peer not discovered, skipped", .warn); return }
        sending = true
        Task { [weak self] in
            guard let self else { return }
            defer { Task { @MainActor in self.finishSend() } }
            do {
                let link = try await TransportConnector.shared.connect(to: peer, localName: self.localName(),
                                                                       allowed: self.settings.enabledTransportStrategies)
                defer { link.cancel() }
                try await link.sendSecureObject(SessionHello(kind: .clipboard))
                try await link.sendSecureObject(payload)
                DebugLog.log("clipboard: sent \(payload.text != nil ? "text" : "image") to \(peer.name)")
            } catch {
                DebugLog.log("clipboard: send failed — \(error.localizedDescription)", .warn)
            }
        }
    }

    private func finishSend() {
        sending = false
        if pendingResend { pendingResend = false; poll() }
    }

    /// Incoming payload from a trusted peer → write to the local pasteboard.
    func receive(_ payload: ClipboardPayload) {
        guard settings.clipboardSyncEnabled, payload.isWithinLimits, !payload.isEmpty else { return }
        let pb = NSPasteboard.general
        pb.clearContents()
        if let t = payload.text { pb.setString(t, forType: .string) }
        if let img = payload.image { pb.setData(img, forType: .png) }
        state.noteOwnWrite(count: pb.changeCount)
        DebugLog.log("clipboard: received \(payload.text != nil ? "text" : "image")")
    }

    static func readLocal() -> ClipboardPayload? {
        let pb = NSPasteboard.general
        if let s = pb.string(forType: .string) { return ClipboardPayload(text: s, image: nil) }
        if let png = pb.data(forType: .png) { return ClipboardPayload(text: nil, image: png) }
        if let tiff = pb.data(forType: .tiff), let rep = NSBitmapImageRep(data: tiff),
           let png = rep.representation(using: .png, properties: [:]) {
            return ClipboardPayload(text: nil, image: png)
        }
        return nil
    }
}
```
